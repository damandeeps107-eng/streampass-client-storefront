# StreamPass - D2C OTT Subscription Marketplace

StreamPass is a premium, high-converting D2C OTT subscription storefront. Features include 100% replacement warranty badges, 24/7 Support & Instant Refund Bot (StreamBot), full-screen neutral D2C checkout, Express Myntra/Amazon voucher payments, and real-time order tracking.

## 🚀 Getting Started

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Run Local Development Server**:
   ```bash
   npm run dev
   ```

3. **Production Build**:
   ```bash
   npm run build
   ```

## 💎 Features
- **Modern D2C Light Sage Neutral Aesthetic**: Clean edge-to-edge layout matching premium reference UI.
- **Unified Catalog**: Netflix 4K, YouTube Premium, Spotify, Prime Video, Hotstar, SonyLIV, Zee5, Aha, Apple TV, Crunchyroll.
- **Express UPI Voucher Checkout**: Myntra E-Gift Card & Amazon Pay Voucher integration.
- **Order Tracker Modal**: Live Approved / Rejected (with Admin reason) / Under Review status tracking.
- **StreamBot Assistant**: 24/7 AI support & refund processing bot.
